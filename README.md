# Pemrograman Backend Lanjut dengan Go

Repository ini berisi latihan Week 1 dan API Student Week 2.

## Struktur Project

```text
latihan-fiber/
  main.go
  variabel/main.go
  pointer/main.go
  struct/main.go

api-student/
  main.go
  model.go
  helper.go
  handler.go
```

## Menjalankan Week 1

```powershell
go run ./latihan-fiber
go run ./latihan-fiber/variabel
go run ./latihan-fiber/pointer
go run ./latihan-fiber/struct
```

## Menjalankan Week 2

```powershell
go run ./api-student
```
